**START / CONTINUE this repository.** Read the README, purpose, current implementation, issues, plans, and trackers. Inspect existing code before editing. Identify the highest-priority incomplete and unclaimed task belonging here. Claim it, mark `IN_PROGRESS`, implement, verify with relevant tests, record evidence/status, commit, release the claim, re-check, and continue automatically.
